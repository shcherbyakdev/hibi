# Toolbox Widget Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A toolbox widget (Today tasks with pomodoro start, big countdown, focus time) that the user docks beside the content or floats over it.

**Architecture:** Pure helpers in `features/time/model.ts` derive pomodoros-done and focus time from the existing `time_entries` rows exposed by `useTimer()`. A new `features/toolbox/` holds the placement store (localStorage via `useSyncExternalStore`), the card, and a host mounted once in `AppShell` that renders the card docked (column) or floating (portal, fixed, draggable).

**Tech Stack:** Next 16.4 App Router (client components), React 19.3, Tailwind v4 tokens, lucide icons, Dexie live queries, Vitest.

**Spec:** `docs/superpowers/specs/2026-11-16-toolbox-design.md`

## Global Constraints

- No schema change, no new dependencies.
- Client-only; must work in hosted and desktop (static export) editions.
- Read `node_modules/next/dist/docs/` before using any Next API.
- Placement in localStorage key `todo:toolbox`, every read/write in try/catch; default mode `hidden`.
- Docked column 320px, `md` and up; below `md` docked renders as floating.
- ▶ in the widget = `timer.start(id, { pomodoro: true })`.
- `FOCUS_GOAL_SECONDS = 4 * 3600` with a `ponytail:` comment (becomes a pref when needed).
- hibi tokens (`primary`/`brand`, `--radius`, Geist Mono clocks, uppercase mono labels), not the reference's orange.
- `npm run verify` green before each commit.

## Review Focus

- Window resized smaller while floating → card stays fully on screen (clamp on resize) — test in Task 2.
- Corrupt/foreign JSON in `todo:toolbox` → falls back to `{ mode: "hidden" }`, no crash — test in Task 2.
- Midnight rollover with the widget open → dashes and focus time reset (day bounds come from `useToday()`, which re-renders) — test in Task 1 (session started yesterday not counted today).
- Running task deleted or marked done from elsewhere → widget timer still shows the running session's clock, list drops the row; no crash on missing item — handled in Task 3 (`item ?? null` guard).
- Two widgets' worth of state (docked→floating switch) never starts a second timer → all actions go through `useTimer()`; no local timer state — enforced in Task 3 review.

```ts
  const day = [at("00:00:00"), at("23:59:59") + 1000] as const;
  const es = [
    entry({ start: "09:00:00", end: "09:25:00", planned: 1500 }),           // done
    entry({ start: "10:00:00", end: "10:10:00", planned: 1500 }),           // paused early

  expect(pomodorosDone(es, "a", ...day, at("16:00:00"))).toBe(2); // the open one reached 25m

it("sums focus time for sessions started in the day", () => {

  expect(focusSeconds(es, at("09:30:00"), at("23:59:59"), at("11:00:00"))).toBe(1500);
});
```

**Interfaces:**
- Produces:
  - `type ToolboxMode = "hidden" | "docked" | "floating"`
  - `type Placement = { mode: ToolboxMode; last: "docked" | "floating"; x: number; y: number }` (`last` = mode F restores)
  - `parsePlacement(raw: string | null): Placement` — default `{ mode: "hidden", last: "floating", x: -1, y: -1 }` (`-1` = "bottom-right, computed at render")
  - `clamp(pos: {x: number; y: number}, size: {w: number; h: number}, viewport: {w: number; h: number}, margin = 8): {x: number; y: number}`
  - `useToolbox(): Placement & { setMode(m: ToolboxMode): void; toggle(): void; moveTo(x: number, y: number): void }`
  - `TOOLBOX_EVENT = "todo:toolbox-change"`
